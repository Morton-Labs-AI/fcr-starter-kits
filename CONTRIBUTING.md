# Contributing

Open an issue describing a reproducibility failure, missing explanation, or
proposed example. Include your operating system, runtime version, command,
expected behavior, and observed output. Remove credentials and private data.

For a pull request:

1. Keep a small, educational example with a beginner route and a clearly
   labeled advanced route. Explain prerequisites and expected outputs.
2. Preserve source licenses, stable identifiers, units, uncertainty,
   assumptions, and source revisions. Describe derived data as derived.
3. Run the kit's check command. Include actual execution evidence when
   claiming a solver result. A render is not a numerical validation.
4. Update documentation and review images when behavior or geometry changes.

By contributing original material, you agree to offer it under MIT OR
Apache-2.0. Do not submit material you lack permission to share. Upstream
changes should preferably be contributed upstream and then pinned here.
Maintain respectful technical discussion. Maintainers review contributions;
inclusion is not an endorsement of a contributor for employment.
